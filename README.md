# 💼 Responsive Internship Board

A modern and responsive web-based Internship Board designed to help students and job seekers discover internship opportunities based on their skills and preferred location.

## ✨ Features

- 🔍 Search internships by title or skill
- 📍 Filter internships by location
- 💼 Company and internship details
- ⏳ Internship duration
- 🛠️ Required skills
- 📱 Fully responsive design
- 🎨 Clean and modern user interface
- ⚡ Fast and simple navigation
- 📝 Apply Now button

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
